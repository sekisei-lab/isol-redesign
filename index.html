モデルから、生成する。
だから変更に強い。

GeneXusは業務ルールをナレッジベースとして定義し、複数プラットフォーム向けのコードを自動生成するローコード基盤。属人的な保守から脱却し、内製化を可能にします。

  • 業務ルールと画面・DBを一元管理
  • 仕様変更が全体に整合して反映される
  • お客様の内製チームへ段階的に移管

OrderInspection.gx
// 業務ルールを1箇所に定義 → 全プラットフォームへ生成
Transaction Shipment {
  Rules
    Error("在庫が不足しています")
      if ShipQty > StockQty;
    Msg("検品完了") on AfterComplete;
  Events
    Event AfterInsert
      Call(UpdateTaskTracking, ShipId);
}
// build →  ✔ Web  ✔ Mobile  ✔ API  ✔ DB
